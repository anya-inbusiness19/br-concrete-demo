# BR Concrete Finishing — Demo Website

Multi-page demo site for BR Concrete Finishing (Athens, AL). Demo by A’Nya.

**Pages:** Home · Services · Our Work · Reviews · Free Estimate · Admin

- Animated hero with floating cards, rating bars, cure ring, page transitions and scroll reveals (respects reduced-motion)
- Real HomeAdvisor reviews and rating breakdown
- Free-estimate form feeds the Admin dashboard
- Admin (`#admin`, demo PIN `1234`): estimate requests with status, photo uploads, featured reviews, business info

Single file (`index.html`), no build step. Hosted with GitHub Pages from the `main` branch.

> Admin data is saved in the viewer's browser only (demo). Connect a database or email service before going live.
